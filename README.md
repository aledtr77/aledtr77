## How I work

I start with the purpose of the product: what it should do, who it is for and
what must work before it can be published.

AI supports much of the implementation, refactoring and documentation. My role
is to direct the process, evaluate the working result, run the required checks
and maintain the released product.

The repositories use a structured verification and release workflow:

- Automated checks for JavaScript, CSS, HTML and production builds
- Behaviour, accessibility and security checks where relevant
- GitHub Actions for continuous integration and deployment workflows
- Separate demo and deliverable builds when a project is intended for reuse
- Final packages rebuilt and tested in a clean environment before release
- Versioned releases, documentation and recorded project limitations
- Deployment to the web hosting platform best suited to each product

I use each project to improve my technical understanding while continuing to
build, test and publish real products.
