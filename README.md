## Selected work

### [codedge.it](https://codedge.it)

A bilingual front-end reference with 418 glossary entries, 12 tutorials, four
browser-based tools and four documented UI components.

- Multi-page Vite build deployed through GitHub Actions to Cloudflare Pages
- Automated language-parity, browser smoke and accessibility checks
- Client-side tools that keep user files on the device

[Live site](https://codedge.it) · [Source](https://github.com/aledtr77/codedge)

### [Palette Extractor](https://palette-extractor-7hm.pages.dev/)

Turns an image into UI colour roles, WCAG contrast results, CSS custom properties
and JSON. Image processing stays entirely in the browser.

- Perceptual colour comparison in Lab and WCAG contrast calculations
- Camera, clipboard and file-export workflows
- 133 automated tests across colour maths, extraction and output contracts

[Live tool](https://palette-extractor-7hm.pages.dev/) ·
[Source](https://github.com/aledtr77/palette-extractor)

### [FitSculpt Pro](https://fitsculpt-pro.pages.dev/)

A responsive landing-page template for physique and body-sculpting coaches, designed
around one clear conversion path from first visit to booking.

- Light and dark themes, responsive imagery and accessible navigation
- Metrics calculator, filterable programmes, pricing toggle and booking dialog
- Public source intended as a practical HTML, CSS and JavaScript reference

[Live demo](https://fitsculpt-pro.pages.dev/) ·
[Source](https://github.com/aledtr77/template-fitsculpt-pro)

## How I work

- Start with semantic structure, responsive layout and keyboard-accessible controls.
- Verify behaviour in the browser, at desktop and mobile widths, and in automated CI.
- Choose the smallest stack that fits the product, then keep the code modular,
  documented and straightforward to run locally.
